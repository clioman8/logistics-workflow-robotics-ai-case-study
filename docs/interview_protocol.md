# Interview Protocol

## Logistics Workflow

1. What was the exact sequence of tasks during outbound work?
2. Was barcode scanning done with PDA, handheld scanner, or terminal?
3. What happened when scan errors occurred?
4. How were product mismatches handled?
5. How were packing errors detected?
6. Who created daily reports?
7. What safety issues occurred most often?

## Robotics AI Relevance

1. Which tasks were repetitive enough for automation?
2. Which tasks required human judgment?
3. Which tasks involved visual recognition?
4. Which parts could be supported by AMR/AGV?
5. Which parts required barcode/OCR/label recognition?
